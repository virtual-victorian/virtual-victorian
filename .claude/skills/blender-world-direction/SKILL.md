# Blender World Direction

Read the one guide matching the setting. Combine guides only when the premise itself crosses settings.

| Setting | Guide |
|---|---|
| Post-apocalypse, zombies, invasion, dystopia | [apocalyptic worlds](references/apocalypse-worlds/guide.md) |
| Underwater, desert, arctic, jungle, underground | [biome worlds](references/biome-worlds/guide.md) |
| Medieval, high, dark, or urban fantasy | [fantasy worlds](references/fantasy-worlds/guide.md) |
| Western, pirate, samurai, Viking, ancient, Victorian, military | [historical worlds](references/historical-worlds/guide.md) |
| Space, hard sci-fi, cyberpunk, steampunk, solarpunk and related punk settings | [sci-fi and punk worlds](references/sci-fi-punk-worlds/guide.md) |

World direction defines the shared design language. Use `blender-environment-modeling`, `blender-prop-modeling`, or another discipline to build the actual assets.
